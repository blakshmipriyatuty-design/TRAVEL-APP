# TRAVEL-APP
# Project Overview
The Travel Booking App UI is a mobile application interface designed using Figma. The application provides users with a simple and attractive interface to search for travel destinations, book tickets and search the special dishes
This project was created as part of the UI/UX Design Laboratory to demonstrate the principles of user interface design and user experience.

# Objective
To design a modern, user-friendly, and visually appealing mobile application for booking travel tickets and exploring travel destinations.

# Features
- Destination Details
- Transportation Selection
- Payment Screen
- Booking Confirmation
- User Profile

# Tools Used
Figma
